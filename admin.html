Gemini 자동 브리핑 설정

API 키는 사이트 코드에 넣지 않고 GitHub Actions Secret에만 저장합니다. 방문자는 키를 볼 수 없고, 생성된 브리핑만 읽습니다. 이 페이지는 사이트 운영자를 위한 안내이며, 공개 메뉴에는 노출되지 않습니다.

설정 순서

  1. GitHub 저장소에서 Settings → Secrets and variables → Actions로 이동합니다.
  2. New repository secret을 누르고 이름을 GEMINI_API_KEY로 입력합니다.
  3. 값에는 Gemini API 키를 붙여넣습니다.
  4. Actions → Update Daily Market Briefing → Run workflow를 눌러 한 번 실행합니다.

이후 예약된 시간에 data/today.json이 자동 갱신됩니다.

관련 파일

.github/workflows/update-market.yml scripts/update-market.js data/today.json

키를 채팅이나 공개 저장소 코드에 넣으면 안 됩니다. Secret에만 넣어야 합니다.

관리 페이지는 안내용입니다. 실제 업데이트는 GitHub Actions에서 실행됩니다.
